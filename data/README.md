# Controlled Mock Dataset

This folder contains deterministic mock data for Lab 3.

- `products.json`: product catalog with price, category, weight, and stock.
- `coupons.json`: coupon validity and discount percentages.
- `shipping_rates.json`: shipping base cost and per-kg rates by city.

The dataset is intentionally controlled so chatbot answers can be compared against tool-grounded ReAct agent answers with known expected results.
